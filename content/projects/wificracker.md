## 📖 Description

WPApwn pronounced as WPA pwn, is an automated wifi cracker that captures WPA2 4-way handshake and cracks them via a dictionary attack.

It is still in development and I plan on adding the following features ->

1. Denial of Service
2. Offline brute forcing
3. PMKID Attack Support
4. Automated message when attack is completed.

The tool is quite simple to use, just follow the instructions on my [github](https://github.com/AdityaaTikoo) page.

---

## Inspiration

I got the idea of creating this tool from a show called [Mr Robot](https://en.wikipedia.org/wiki/Mr._Robot), there was a scene in which the main protagonist “hacks” into his neighbour’s wifi manually. I thought to myself that I could probably automate this.

Yes I know that you can just buy a [wifi pineapple](https://shop.hak5.org/products/wifi-pineapple) and automate wifi pentests but those things cost 240 dollars !!!.

This is a free and opensource tool.
